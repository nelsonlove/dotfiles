# cargo binaries — installed by the `cargo` step of install/install.sh.
#
# Format: one crate per line, then optional tokens.
#
#     <crate>[  from=<source>]  [<flag> …]
#
# `from=` names what to install when it differs from the crate name (e.g. a
# local path or a --git spec); `from=?` marks a source we do not know, and
# those entries are SKIPPED rather than guessed. See install/pipx-list.txt for
# the same format at more length.
#
# This step builds from source, so it is the slow one. It is scopable like any
# other: `install/install.sh --skip cargo` to leave it out.
#
# This list is a UNION across Nelson's machines and refresh-inventory.sh never
# removes from it — `cargo install --list` is empty on the MacBook Air, so the
# previous dump-and-overwrite emptied this file whenever it ran there. To drop
# a crate, delete its line by hand.
#
# emacs-lsp-booster is the published crate (blahgeek/emacs-lsp-booster): the
# recorded 0.2.1 is its current crates.io release, so the bare name resolves.
