# pipx apps — installed by the `pipx` step of install/install.sh.
#
# Format: one package per line, then optional tokens.
#
#     <package>[  from=<source>]  [<flag> …]
#
# `from=` names what to install when it differs from the package name, which is
# the normal case here: most of these are Nelson's own repos, not published
# packages. `from=?` means the source is not recorded — the installer SKIPS
# those and says so, rather than guessing. Do not replace a `?` with a bare
# name to make it install: `apple-notes` is also an unrelated project on PyPI,
# and a bare name would fetch a stranger's code. Fill in the real path, or run
# install/refresh-inventory.sh on the machine that has the app.
#
# `#` comments and blank lines are ignored. Already-installed apps are left
# alone rather than upgraded, matching `brew bundle --no-upgrade`.
#
# This list is a UNION across Nelson's machines, like install/launchagents/.
# refresh-inventory.sh ADDS what is newly installed and never removes. That is
# not a preference: pipx reports zero apps on the MacBook Air and ten on the
# MacBook Pro, so the previous dump-and-overwrite truncated this file to empty
# whenever it ran on the Air. To drop an app, delete its line here by hand.
